Padreen —— 把华为 MatePad Paper（墨水屏）当电脑的第二块显示器
====================================================================

【它是什么】
电脑上运行 Padreen（托盘小程序），平板上运行 Padreen App：电脑里多出一块"只给平板用的显示器"，把窗口拖过去就显示在墨水屏上；
平板屏幕上用手指点按、拖动窗口、拖动滚动条，就像触摸屏一样。连接可以用 Wi-Fi（局域网自动发现 + 配对码），也可以用 USB 线。

【安装】
· 安装包（Padreen-Setup-x.y.z.exe）：双击运行，默认装到 D 盘。需要管理员权限一次，用来添加：
    - 两条 Windows 防火墙入站规则（TCP 38702、UDP 38703；只允许本地网络内的设备、只对本程序）——平板通过 Wi-Fi 连电脑用；
    - 虚拟显示器驱动（Parsec VDD 0.41，微软签名；电脑里已经有就跳过）——给平板一块虚拟屏；
  卸载时这些会一并移除。除此之外电脑上不会安装任何东西，也不改任何系统全局设置。
· 绿色版（文件夹）：直接运行 padreen.exe；首次运行会询问是否添加防火墙规则（弹出一次管理员授权）；虚拟显示器驱动需要管理员运行一次 driver\install-vdd.ps1。
· 从旧版升级：Padreen 以前叫 PaperDisplay（电脑端程序叫 PaperHost）。安装包会先自动卸载旧版（旧程序、旧电源助手服务、旧防火墙规则、旧快捷方式；虚拟显示器驱动不动），
  设置和平板配对记录原样保留，Padreen 第一次运行时自动接手；旧的「开机自动启动」也会变成启动 Padreen。平板上的旧 App「PaperDisplay」：用 USB 连一次会被自动卸载，
  或者在新 App 主页点「卸载旧版」。

【平板端安装】
· 方法一（USB，最省事）：平板 设置 → 系统和更新 → 开发人员选项 → 打开"USB 调试"，用数据线连电脑并选"始终允许"；Padreen 会自动把平板 App 装上
  （平板上弹"风险提示"时点「继续安装」——系统安全确认，只有这一次）。
· 方法二（不用 USB）：把安装目录里的 padreen.apk 拷到平板（微信/网盘/U 盘等），在平板上点开安装。

【第一次连接：配对】
配对 = 电脑和平板互相记住对方，之后自动连接。三种办法：
1. 配对码（Wi-Fi）：电脑托盘图标 → 左键打开主界面 →「配对新平板…」，屏幕上显示 9 位配对码（5 分钟有效，输错 5 次作废）。
   平板上打开 Padreen，列表里会自动出现局域网里的电脑，点电脑旁的「配对…」，用屏幕上的数字键盘输入配对码 → 自动连接。
2. USB 线：用 USB 线连一次（平板 App 装好后），程序自动配对，不用输入任何东西。之后拔线就能用 Wi-Fi。
3. 平板找不到电脑时：点「手动输入电脑地址」，输入电脑的局域网 IP（如 192.168.1.20）。
（MatePad Paper 没有摄像头，所以不能扫码。）
一台平板可以配对多台电脑，一台电脑也可以配对多台平板（同一时刻只服务一台）。不用了：电脑「已配对的平板…」里取消配对；平板列表里点「忘记」。

【合上笔记本盖子 / 切出去再切回来】
· 合盖：连接平板期间可以直接合上笔记本盖子（Surface 的键盘盖也一样），电脑不会睡眠，平板继续显示、继续能触控。
  做法：安装包带一个很小的「电源助手」Windows 服务（需要管理员安装一次）。只在连接平板期间，它把当前电源计划的「合上盖子时」临时改成「不采取任何操作」，
  断开 / 退出 / 程序崩溃后 15 秒内自动还原（服务重启、重启电脑也会还原）。同时程序会让电脑不因空闲而睡眠。
  如果平板这块屏成了电脑唯一的屏幕（合盖又没接别的显示器），程序还会让它不因「关闭显示器」的超时而黑屏/锁屏。
  合盖/开盖时 Windows 会重排显示器，程序会自动重新抓取虚拟屏，平板约 1–9 秒内恢复，窗口位置不变。
  （主界面「连接期间合上笔记本盖子也不休眠」可关；没装电源助手时合盖会按系统设置处理——主界面会提示。）
· 平板端：切到别的 App、按返回/Home、息屏都不会断开连接（有一条「正在作为第二块显示器使用」的常驻通知保活）；回到 Padreen 时整屏自动重绘一次。
  在平板主页顶部有「已连接」横幅：「返回显示」回到画面，「断开」才真正断开。电脑端不会因为你切出去而把虚拟屏撤掉。
· Wi-Fi 临时中断、平板 App 被关掉/重启：电脑会保留虚拟屏最多 45 秒（窗口不会被移走），平板 App 重新打开（或自动重连）后继续用；平板上点「断开」则立刻结束。

【日常使用】
· 电脑端：运行 Padreen（可勾选开机自动启动；插着 USB 线时默认优先用 USB，主界面可改成始终走 Wi-Fi），托盘出现小图标（灰=等待，橙=准备中，绿=已连接，红=出错）。左键打开主界面，右键是快捷菜单。
· 平板端：打开 Padreen → 自动搜索并连接上次用的电脑（列表里也可以手动点「连接」）。屏幕出现电脑的第 3 块屏；把窗口拖过去就能用。
  结束：平板主页点「断开」（不再自动重连）；或电脑托盘「退出」。返回手势只是离开显示画面，连接还在。
· USB 线：插上就自动装/开平板 App 并连接，拔线虚拟屏自动消失。
· 无线比 USB 多约 15–20 毫秒延迟；通信全程加密并双向认证，没配对的设备连不上。

【三指手势（平板上）】
· 三指同时轻点 = 整屏刷新；三指上滑 = 多桌面（电脑的 Win+Tab）；三指下滑 = 窗口切换（Ctrl+Alt+Tab，切换器会停在屏幕上，点一下要切到的窗口；想要普通 Alt+Tab 就把 padreen.ini 里的 gesture_down 改成 alttab）。
  这些手势不会把任何点击传给电脑；开启后单指点按会晚约 0.06 秒，不需要可以在平板主页关掉。
· 触控：点按钮、长按（右键）、拖窗口标题栏、拖滚动条、拖动内容平移、双指缩放（取决于应用）。电脑端用 Windows 触控注入：不会移动鼠标指针、不改系统设置。
  以管理员权限运行的程序收不到触控（Windows 安全限制）；手写笔目前按手指处理。
· 整屏刷新（清残影）：平板上三指同时轻点一下；或电脑主界面「立即全屏刷新」。整屏会黑白闪一下并刷成 16 级灰阶。
  程序平时不会自己整屏刷新。会整屏刷新的只有：① 你主动触发（三指轻点 / 主界面按钮 / 切换极速↔画质）；② 每次新连接的第一帧；③ 平板从后台回到前台（别的 App 画过屏幕，必须重绘）；④ 连接中断后平板被重启过（屏幕内容不再是电脑画的）——平板还留着原来的画面时，重连只补发这期间变化的部分，不闪。
  大幅度的页面变化（翻页、切换窗口、整页滚动）是快速黑白更新（A2），不是整屏刷新，会等画面停稳后一次画出。

【平板转方向 / 音量键】
· 自动旋转（默认开）：把平板立起来/拿在手里转到竖屏，电脑上这块屏幕会自动变成竖屏（1404×1872），转回横屏再变回来（1872×1404）。
  做法：平板自己读加速度计判断怎么拿的（这台平板系统自带的旋转监听没有接传感器，所以 App 自己判断），转动约 50° 就触发，不用转到底；
  平板把方向告诉电脑，电脑把"平板这块虚拟屏"的分辨率切到对应的横/竖版本并重新发整屏，约需 1–2 秒（期间平板显示一张空白页）；
  只改这一块虚拟屏，窗口会被 Windows 按新形状重新排布。横屏转 180°（数据线在左边）只是重绘一次，电脑不需要变。
  **平放在桌上（倾斜不到约 10°）时不会改变方向**，一直保持当前显示的方向（平放时转动平板，重力方向不变，传感器本来就感觉不到；这台平板也没有陀螺仪/磁力计）。
  平板退出再回到显示页时，也保持离开时的方向。
  开关有两处：电脑主界面（托盘右键菜单里也有）的「自动旋转」，和平板主页的「自动旋转」。任何一边关掉，平板就留在横屏、电脑上的平板屏也一直是横屏；
  电脑上的开关连接着也能随时切（竖屏时关掉会立刻变回横屏）。也可以在 padreen.ini 里写 rotate=0。需要驱动里登记过 1404×1872 模式（安装包会登记）。
· 音量键：Padreen 在平板最前面（正显示着电脑桌面，或停在 Padreen 主页但已连着电脑）时，平板侧面的音量键调的是电脑的音量（相当于键盘上的音量键），
  不再调平板自己的音量，平板的音量提示也不会弹出来；没连电脑、或切到了别的 App，还是调平板音量。不需要可以在平板主页取消「音量键调节电脑音量」。
  （音量提示由 Windows 显示在电脑自己的屏幕上；平板是电脑唯一的屏幕时会出现在平板上。）

【设置（电脑主界面）】
· 刷新方式：DU（稳妥，残影少）/ A2 6 帧（默认，更跟手）/ A2 7–9 帧 / A2·MIX。
· 自动补灰阶：关闭（默认，文字纯黑白，不会自己局部刷新）/ 少量 / 完整。
· 平板这块屏使用纯白壁纸：默认开，只换"平板这块屏"的壁纸（照片壁纸在墨水屏上满屏噪点又拖影），退出时还原。电脑自己的屏幕和壁纸一概不动：
  程序只对平板这块虚拟屏调用 Windows 的「按显示器设置壁纸」，并且连接期间每 2 秒检查一次，万一哪块真实屏幕出现了这张白图会立刻改回原样；
  退出时还会把这张白图从 Windows「个性化 → 背景 → 最近使用的图片」里去掉。
· 自动旋转（见上）、触控输入、允许平板通过局域网连接、开机自动启动（只为当前用户）。
更多选项见 padreen.ini.sample（复制为 padreen.ini）。运行日志 padreen.log（主界面「打开日志」）。

【使用建议】
· 墨水屏适合文档、代码、阅读、聊天；不适合视频和快速滚动。
· 虚拟屏默认 150% 缩放左右；觉得字小可以在 Windows 显示设置里给这块屏单独调大（只影响这块屏）。

【常见问题】
· 平板列表里找不到电脑：① 电脑上 Padreen 在运行（托盘有图标）② 电脑和平板连同一个 Wi-Fi（有的路由器开了"AP 隔离/客户端隔离"会互相看不见）
  ③ 防火墙规则在（安装包会加；绿色版托盘菜单「启用局域网连接（需要允许防火墙）」）④ 仍不行就用「手动输入电脑地址」。
· 提示"电脑上没有打开配对窗口"：电脑主界面点「配对新平板…」。提示配对码不对：看窗口里最新的码；输错 5 次要重新打开窗口。
· 电脑托盘一直灰色：确认平板 App 已打开（Wi-Fi），或 USB 调试已开、线是数据线、平板上点过"允许调试"。
· 红色"没有安装虚拟显示器驱动"：安装包会装；绿色版需管理员运行一次 driver\install-vdd.ps1。
· 平板上点 App 图标没反应/白屏：平板 App 需要是最新版（电脑用 USB 连一次会自动升级）。

【文件】
padreen.exe 主程序   padreen.apk 平板 App   adb\ USB 工具   driver\ 虚拟显示器驱动及脚本
设置/配对/日志（padreen.ini、devices.ini（密钥已加密）、padreen.log）：绿色版放在程序目录；用安装包安装后程序目录只允许管理员修改，这些文件放在 %LOCALAPPDATA%\Padreen。

【卸载 / 还原】
安装包：控制面板 → 卸载 Padreen（会移除防火墙规则；驱动只有"由本安装包装的"才会移除）。平板上长按图标卸载 App。
壁纸：正常退出时已还原；若程序被强行结束，下次启动会自动还原。
