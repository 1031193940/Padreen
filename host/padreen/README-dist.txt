Padreen —— 把华为 MatePad Paper 当电脑的第二块显示器
====================================================

【安装】
运行 Padreen-Setup-x.y.z.exe（需要管理员授权一次）。
绿色版：直接运行 padreen.exe。

【使用】
1. 平板：设置 → 系统和更新 → 开发人员选项 → 打开「USB 调试」。
2. 用数据线连电脑，在平板上点「允许」。平板 App 会自动安装（点一次「继续安装」）。
3. 首次运行时按提示安装虚拟显示器驱动：它是 Parsec 的软件，不随 Padreen 分发，
   由程序从 Parsec 官网下载（需要联网，并授权一次）。
4. 电脑上多出一块屏，把窗口拖到平板上即可。

【Wi-Fi 连接】
电脑托盘图标 → 左键打开主界面 →「配对…」，屏幕上显示配对码。
平板打开 Padreen，点电脑旁的「配对」，输入配对码。之后自动连接。
平板找不到电脑时，点「输入 IP」。

【三指手势】
轻点 = 整屏刷新（清残影）　上滑 = 多桌面（Win+Tab）　下滑 = 切换窗口

【卸载】
控制面板 → 卸载 Padreen。虚拟显示器驱动不会一起卸载：
设备管理器 → 显示适配器 → Parsec Virtual Display Adapter → 卸载设备。
