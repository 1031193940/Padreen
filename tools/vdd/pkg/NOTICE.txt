Padreen - virtual display driver package (third-party software)
================================================================

Padreen needs a "virtual monitor" driver so that Windows gets the monitor that shows the tablet.  That driver is Parsec's software, and it is NOT
part of Padreen: no Padreen download (installer, folder, source archive) contains it, because no permission to redistribute it has been found.  Instead,
when the user agrees (first start, or the tray menu), padreen.exe downloads Parsec's own installers from Parsec's server on that user's PC, checks
them against the SHA-256 values below, takes the four files out of them, and installs them (once, with administrator approval).  The files are
Parsec's, byte for byte as Parsec publishes them; Padreen does not modify them.  They stay under their owners' own terms (Parsec / Unity).

This folder is for developers: tools\fetch-vdd.ps1 puts the same four files here (they are not kept in git) for the scripts next to this file.

  nefconw.exe       nefcon 1.10.0 (Nefarius Software Solutions e.U.), the tool that creates the device and installs the driver.
                    Signed by Parsec Cloud, Inc.  Taken from parsec-vdd-0.45.0.0.exe.
  driver\mm.inf     Parsec Virtual Display Driver 0.41 (Parsec Cloud, Inc.): an IddCx user-mode driver, signed by Microsoft
  driver\mm.dll     (Windows Hardware Compatibility Publisher).  Taken from parsec-vdd-0.41.0.0.exe.
  driver\mm.cat

What the installation changes on the PC:
  - one root-enumerated device "Parsec Virtual Display Adapter" (hardware id Root\Parsec\VDA, class Display); it creates no monitor by itself
  - the driver package in the Windows driver store (oemNN.inf) and mm.dll in %SystemRoot%\System32\drivers\UMDF
  - HKLM\SOFTWARE\Parsec\vdd\0 and \1: the tablet's modes 1872x1404@60 and 1404x1872@60

Remove all of it: Device Manager > Display adapters > "Parsec Virtual Display Adapter" > Uninstall device (tick "Delete the driver software for
this device"), and delete the registry key HKLM\SOFTWARE\Parsec\vdd\0 and \1 (and the keys above them when they are empty); or, for developers with
the package in this folder, uninstall-vdd.ps1 from an administrator PowerShell does all of it:
  powershell -NoProfile -ExecutionPolicy Bypass -File uninstall-vdd.ps1
